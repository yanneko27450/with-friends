Friends with Claude 是一個 Claude Code 外掛。裝了之後，Claude 旁邊會多一個小面板，看得到群組裡誰在線上、在用 Claude 弄哪一類東西，有點像 Discord 顯示朋友在玩什麼遊戲。對話內容不會分享出去。

Friends with Claude is a Claude Code plugin. It adds a small panel next to Claude that shows which friends in your group are online and what kind of thing they're working on, a bit like Discord showing what game your friends are playing. Your conversations are never shared.

只有電腦上看得到：Claude 桌面版的 Code 分頁，或終端機。用手機遙控電腦上的對話時，外掛照樣在跑、照樣分享，只是手機上看不到面板；要停請打 /friends pause。

You'll only see it on a computer: the Code tab in the Claude desktop app, or the terminal. If you drive a computer conversation from your phone, the plugin still runs and still shares; you just can't see the panel. To stop, type /friends pause.

它會傳什麼出去What it sends

朋友看得到的只有下面三樣。你打的字和 Claude 的回答不會送到中繼伺服器（幫大家轉送狀態的伺服器）。

Friends only ever see these three things. Your messages and Claude's replies never go to the relay server (the server that passes statuses between you).

會傳Sent

  • 你自己取的名字（最多 20 字，用暱稱就好）
  • 在不在線：工作中、閒置、離線
  • 一個分類，例如「修錯誤 · 網站」
  • The name you pick (up to 20 characters; a nickname is fine)
  • Whether you're online: working, idle or offline
  • One category, like "Fixing bugs · a website"

不會傳Never sent

  • 你打的字、Claude 的回答
  • 檔案內容、程式碼
  • 資料夾路徑、專案名稱
  • Your messages or Claude's replies
  • File contents or code
  • Folder paths or project names

伺服器另外會收到登入用的金鑰、加入時的邀請碼，以及你的 IP（跟你連任何網站一樣）。

The server also receives your sign-in key, the invite when you join, and your IP address (as any website does).

朋友也看得到你「幾分鐘前開始」做這件事，所以大概知道你什麼時候在用 Claude。

Friends also see how long ago you started, so they can roughly tell when you're using Claude.

分類是從一張固定的清單裡挑的，13 種動作配 12 種對象。伺服器只收清單上的代碼，所以就算外掛有 bug，也送不出你打的一句話。

The category comes from a fixed list of 13 actions and 12 subjects. The server only accepts codes from that list, so even a bug in the plugin can't send out a sentence you typed.

加入之後，你開的每一個 Code 對話都會分享，開新對話時面板也會自己打開。把面板關掉不會停止分享，只是改成每分鐘送一次；想停就用下面的 暫停。

Once you join, every Code conversation you open shares, and the panel opens by itself in new ones. Closing the panel doesn't stop sharing; it just sends once a minute instead. To stop, use pause below.

安全嗎Is it safe?

你跟 Claude 的對話和你在做的東西（程式碼、檔案、專案內容），中繼的管理者和朋友都看不到。外掛送出去的只有名字、在不在線、一個分類。挑分類時，外掛會把你打的字遮掉敏感部分，交給你本來就在用的 Claude 判斷，判斷完只留下分類代碼；那段文字跟你平常用 Claude 一樣只到 Anthropic，不會送到中繼伺服器或任何其他地方。

Your conversations with Claude and what you're working on (code, files, project details) can't be seen by the relay's operator or your friends. It only sends your name, whether you're online, and one category. To pick the category, it masks sensitive bits of what you typed and asks the same Claude you already use. Only the category code is kept. That text goes to Anthropic like any normal Claude message, and never to the relay server or anywhere else.

怎麼做到的，以及其他防護：

How that's enforced, plus other safeguards:

  • 伺服器只收清單上的分類代碼，清單外的值、多出來的欄位都會被拒收。名字也會先清掉控制字元和會把文字方向反過來的字元。
  • 分類是你自己的 Claude 用小模型判斷的，最多每 3 分鐘一次，只看你打的字，不看 Claude 的回答和檔案，會用到一點點你的額度。送去判斷之前，網址、路徑、檔名、email、看起來像金鑰、或寫成「密碼：…」的字串會先換成 [path]、[secret] 這種代號。
  • 朋友的名字只會顯示在面板上，不會進到你的對話，所以就算有人把名字取成一句指令，也碰不到你的 Claude。
  • 加入時你的電腦會拿到一把鑰匙，伺服器只存它的 SHA-256 雜湊，就算資料庫外流也沒人能冒充你。邀請碼是 128 位元的亂數，猜不到。
  • 伺服器有大概的流量限制：同一個 IP 每分鐘大約 600 次、加入每小時大約 10 次，每次請求最多 4 KB，一個群組最多 10 人。官方中繼一律走 HTTPS 加密；邀請網址開頭不是 https:// 的不要加入。
  • 只加入你認得、信任的人給的邀請。中繼可以是任何人架的，加入就是連上對方的伺服器。
  • 分類 24 小時後從資料庫刪掉。你退出群組，伺服器就刪掉你那筆；群組沒人了，整組刪掉。
  • 這一頁不載入任何外部字型、腳本或追蹤工具，瀏覽器的安全設定（CSP）也只允許這個網址自己的檔案。
  • The server only accepts category codes from the list. Anything off the list, or any extra field, is rejected. Names are cleaned of control characters and characters that flip text direction.
  • Your own Claude picks the category with a small model, at most every 3 minutes. It only looks at what you type, never Claude's replies or your files, and it uses a little of your quota. Before that, URLs, paths, file names, emails and anything that looks like a key or is written as "password: …" get swapped for placeholders like [path] and [secret].
  • Friends' names only show up in the panel, never in your conversation, so even a name written as an instruction can't reach your Claude.
  • When you join, your computer gets a key and the server stores only its SHA-256 hash. Even if the database leaked, nobody could log in as you. Invites are 128-bit random codes, so they can't be guessed.
  • The server has rough rate limits: about 600 requests a minute per IP and about 10 join attempts an hour. Requests are capped at 4 KB and a group at 10 people. The official relay always uses HTTPS; don't join an invite whose address doesn't start with https://.
  • Only join invites from people you know and trust. Anyone can run a relay, and joining connects you to their server.
  • Categories are deleted from the database after 24 hours. When you leave, your record is deleted, and an empty group is deleted entirely.
  • This page loads no outside fonts, scripts or trackers, and its Content Security Policy only allows files from this address.

用之前要知道的限制Limits to know before you join

  • 官方中繼（就是這頁的網址）由這個專案的開發者管理；群組如果用的是別人自己架的中繼，管理的就是那個人。
  • 管理者看得到群組裡每個人的名字、在不在線、分類、時間和 IP；對話內容看不到，因為沒傳上來。
  • 伺服器和外掛的程式隨時可能更新。外掛的自動更新預設是關的：加入群組時會問你一次要不要開，不開的話要你自己按更新才會換新版；開了的話，新版會在背景自己裝上、不再問你。不管哪種，每次更新都等於再相信一次管理者當時放上去的版本（原始碼和每一版的紀錄在 GitHub，見 SECURITY.md）。
  • 邀請那一行請不要轉傳。拿到的人都能加入，外掛裡也還沒有踢人的按鈕；建立者可以打 /friends rotate 換邀請碼，但只擋得住之後的人。
  • 還沒請專業的人做資安檢查，所以現在只找熟的朋友試用。
  • 「刪掉」是從資料庫刪除；Cloudflare 的時間回溯功能在 30 天內還能還原。
  • The official relay (this page's address) is run by the project's developer. If your group uses a relay someone set up themselves, that person runs it.
  • The operator can see each member's name, online status, category, timing and IP address. Not your conversations, because they're never sent.
  • The server and the plugin can be updated at any time. Auto-update is off by default: when you join a group the plugin asks once whether to turn it on. If you don't, yours only changes when you press Update; if you do, new versions install in the background without asking. Either way, each update means trusting what the operator has published at that moment (the source and every version are on GitHub, see SECURITY.md).
  • Please don't forward the invite line. Anyone who has it can join, and the plugin has no kick button yet. The creator can type /friends rotate for a new invite, but that only stops people who haven't joined.
  • No professional security review yet. That's why it's only being tried with close friends for now.
  • "Deleted" means removed from the database. Cloudflare's point-in-time recovery can still restore it for 30 days.

怎麼裝How to install

需要 Claude Code 2.1.295 以上。桌面版更新到最新就好；不確定的話，在對話框打 /status 看版本。朋友傳給你的邀請訊息裡已經有下面這些步驟，照著做就好。

You need Claude Code 2.1.295 or newer. Updating the desktop app is enough. Not sure? Type /status in the chat box to see the version. The invite your friend sent already has these steps.

  1. 把這段話傳給 ClaudeSend this to Claude

    在 Claude 桌面版的 Code 分頁（或終端機）開一個對話，只貼這一段送出，不要把朋友傳來的整則訊息貼給 Claude（裡面有邀請碼）。Claude 通常會先問你允不允許；不管有沒有問，都請確認它跑的就是這兩個指令，而且網址是 https://friends-status-relay.friends-status-relay.workers.dev/marketplace.json，對不上就不要裝。外掛會用你電腦的權限執行，所有 Claude 外掛都是這樣。

    Open a conversation in the Code tab of the Claude desktop app (or the terminal) and send just this paragraph, not your friend's whole message (it contains the invite). Claude usually asks before running a command; either way, check it runs exactly these two commands and that the address is https://friends-status-relay.friends-status-relay.workers.dev/marketplace.json. If it doesn't match, don't install. Like every Claude plugin, it runs with your computer's permissions.

    請幫我安裝一個 Claude Code 外掛，依序執行這兩個指令：claude plugin marketplace add https://friends-status-relay.friends-status-relay.workers.dev/marketplace.json 然後 claude plugin install with-friends@with-friends。找不到 claude 指令的話，用環境變數 CLAUDE_CODE_EXECPATH 裡的執行檔（Claude 桌面版內附的 Claude Code）。裝好跟我說。

    Please install a Claude Code plugin for me by running these two commands: claude plugin marketplace add https://friends-status-relay.friends-status-relay.workers.dev/marketplace.json and then claude plugin install with-friends@with-friends. If the claude command isn't found, use the executable in the CLAUDE_CODE_EXECPATH environment variable (the Claude Code that comes with the Claude desktop app). Tell me when it's done.

  2. 開一個新對話Start a new conversation

    外掛在對話開始時才會載入，已經開著的對話看不到它。

    Plugins load when a conversation starts, so one that's already open won't have it.

  3. 貼上朋友給你的邀請那一行Paste the invite line your friend sent

    長得像這樣，送出後會問你要叫什麼名字：

    It looks like this. After you send it, you'll be asked what name to show:

    /friends join https://friends-status-relay…#xxxx

    之後想再打開面板，打 /friends。面板預設是英文，按面板上的語言鈕可以換成中文。

    Type /friends to bring the panel back later.

Claude 沒有幫你裝的話If Claude doesn't install it

有裝終端機版 Claude 的話，可以自己在終端機跑這兩行，做完一樣接第 2 步：

If you have the terminal version of Claude, run these two lines yourself, then carry on from step 2:

claude plugin marketplace add https://friends-status-relay.friends-status-relay.workers.dev/marketplace.json
claude plugin install with-friends@with-friends

想先看程式碼的話，安裝清單裡有安裝檔的網址和 SHA-256。SHA-256 只保證下載過程沒出錯，防不了管理者自己換掉檔案。

想自己開一個群組Starting your own group

裝好後在新對話依序打 /friends relay https://friends-status-relay.friends-status-relay.workers.dev 和 /friends create 你的名字，再到面板按「複製邀請碼」。

After installing, type /friends relay https://friends-status-relay.friends-status-relay.workers.dev then /friends create your-name in a new conversation, and press "Copy invite" in the panel.

To read the code first, the install list has the package URL and its SHA-256. The hash only proves the download wasn't corrupted; it can't stop the operator from swapping the file.

資料放在哪Where the data lives

官方中繼用的是 Cloudflare Workers 的免費方案。每個群組是一個 Durable Object，裡面是一個很小的 SQLite 資料庫。除此之外沒有別的伺服器，也沒有裝任何分析或追蹤工具。

The official relay runs on Cloudflare Workers' free plan. Each group is one Durable Object holding a tiny SQLite database. There's no other server and no analytics or tracking.

面板開著時，外掛大約每 20 秒送一次狀態，順便拿回朋友的狀態；面板關著時改成每分鐘一次。在不在線只放在記憶體裡，不寫進資料庫，只有加入、退出、換邀請碼、分類換了這類變動才會寫。

With the panel open, the plugin sends your status about every 20 seconds and gets your friends' back in the same request. With it closed, once a minute. Online status stays in memory and never hits the database; only changes like joining, leaving, a new invite or a new category get written.

不想被看到的時候When you'd rather not be seen

/friends pause

暫停分享，朋友只看得到你工作中、閒置或離線，看不到分類。對你所有對話都有效，一直到你打 /friends resume 恢復；面板上的「暫停分享」按鈕是同一件事。

Pauses sharing: friends only see working, idle or offline, with no category. It applies to all your conversations until you type /friends resume. The panel's "Pause sharing" button does the same.

/friends hide

在現在這個資料夾裡做的事，朋友只會看到「在忙」，不會有分類。

For work in the current folder, friends only see "Working", with no category.

/friends leave

退出群組，伺服器上你的資料會被刪掉。要整個移除外掛，先退出，再請 Claude 幫你跑 claude plugin uninstall with-friends@with-friends 和 claude plugin marketplace remove with-friends；沒退出就移除的話，你的名字會一直留在伺服器上。

Leaves the group and deletes your data on the server. To remove the plugin, leave first, then ask Claude to run claude plugin uninstall with-friends@with-friends and claude plugin marketplace remove with-friends. If you uninstall without leaving, your name stays on the server.

有新版的時候，請 Claude 依序跑 claude plugin marketplace update with-friends 和 claude plugin update with-friends@with-friends，再開新對話。

When there's a new version, ask Claude to run claude plugin marketplace update with-friends, then claude plugin update with-friends@with-friends, and start a new conversation.
