自己動手查Check it yourself

  1. 看這一頁的安全標頭Look at this page's security headers

    在瀏覽器按 F12 → Network → 重新整理 → 點這一頁，Response Headers 裡會看到 Content-Security-Policy 寫著只允許 'self'。Press F12 → Network → reload → click this page. Under Response Headers, Content-Security-Policy only allows 'self'.

  2. 核對安裝檔的指紋Check the package fingerprint

    打開 安裝清單，裡面有安裝檔網址和 SHA-256。下載後在終端機跑 certutil -hashfile 檔名 SHA256（Windows）或 shasum -a 256 檔名（Mac）比對。Claude Code 安裝時也會自動比對，對不上就不裝。Open the install list for the package URL and its SHA-256. After downloading, run certutil -hashfile file SHA256 (Windows) or shasum -a 256 file (Mac). Claude Code checks this too and refuses a mismatch.

    指紋本身只保證下載過程沒被改；要確定檔案就是公開的那份程式，看下一條。A fingerprint alone only proves the download wasn't altered. To be sure the file is the public code, see the next step.

  3. 讀原始碼，自己重打一次Read the source and rebuild it yourself

    原始碼在 GitHub，先讀 SECURITY.md。想確定線上的安裝檔沒被換過，用 repo 裡的 relay/worker/build_plugin.mjs 在自己電腦重打一次，算出來的 SHA-256 會跟安裝清單寫的一樣。原始碼每 4～5 版才推一次，所以線上版本比 repo 新的時候會對不上，要等下一次推送。也可以直接請你的 Claude 幫你做這件事。The source is on GitHub; start with SECURITY.md. To be sure the live package wasn't swapped, rebuild it with the repo's relay/worker/build_plugin.mjs: the SHA-256 will match the install list. Code is pushed every 4–5 releases, so when the live version is newer than the repo it won't match until the next push. You can ask your Claude to do this for you.

02

資料庫怎麼管How data is stored

只有一台伺服器，叫「中繼」：它只負責在你和朋友之間轉送狀態，每個群組一個很小的資料庫。沒有別的伺服器，也沒有分析或廣告工具。There's one server, the relay: it only passes statuses between you and your friends, with one tiny database per group. No other servers, and no analytics or ad tools.

放在 Cloudflare 的免費方案，每月 0 元。Runs on Cloudflare's free plan, $0 a month.
